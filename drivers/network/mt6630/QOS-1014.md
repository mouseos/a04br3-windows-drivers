# MT6630 Native 802.11 可変ヘッダー/TID（1014候補）

実機scan成功1012 `b21b869348e0608aa0ad08530ba74313130d5196` を基点とする。
1013のassociation変更、BT共存、親、GPUは取り込まない。実機frame転送・接続・通信・性能は未確認。

## 契約と変更

- 本機Linux gen3 `include/nic/mac.h` の3-address Data24 / QoS26 / QoS+HTC30を共通parserで検査する。
  `nic/nic_rx.c` と `include/nic/nic_rx.h` に従い、descriptorのheader lengthとMACの実長、QoS TIDとdescriptor TIDを照合する。
  LLC/SNAPとEtherTypeはその実長から読む。データと同じdescriptorのRCPI/rate/channelだけを使用する。
- EDCA TID0..7を扱う。A4、fragment、retry、QoS Null、A-MSDU、AMPDU、header-translatedは対応ownerがないため拒否する。
  これらを単に許可してreorderやduplicate処理を捏造しない。HTCは位置だけ検査しOSへ渡す前に除去する。
- Native ExtSTAの受信規則に従い、QoS/HTCを最終owned RX slotへのコピー時に除去し、802.1D priorityを
  `NDIS_NET_BUFFER_LIST_8021Q_INFO` で同期RESOURCES indicationへ渡す。元のOOBはreturn後に復元する。
  暗号frameはHW metadata・鍵・PN・controlled portの検証後だけProtectedを除去する。
- CCMPのnon-QoS replay indexは0。Linux `net/mac80211/rx.c` の `ieee80211_parse_qos` は
  QoSをTID index、non-QoS dataを0としており、management専用index16をdataへ誤適用しない。
- TXはOS所有NBLを既存owned snapshotへ取り込んでから変換する。可変LLC位置でEthernetへ変換し、
  QoS headerまたはNBL 802.1D priorityのTIDをHIFのbyte6 bits4..6へ渡す。
  本機gen3 `include/nic/nic_tx.h` の `ucHeaderPadding` / `TX_DESC_TID_MASK` と
  `nic/nic_tx.c` の `HAL_MAC_TX_DESC_SET_TID` に対応する。
- 未交渉のWMM/BAやAC資源を追加しない。既存TC1/BE（EAPOLは既存control queue）と実page credit処理を維持する。
  TID伝達は実装済みだが、全ACの優先スケジューリングやWMM negotiation成功を意味しない。
- 最大payload2304、MAC+SNAPは24/26/30+8を個別検査。最大storageは2342bytes。
  secured RXの中間payload copyを除去し、最終slotへ一度だけコピーする。
  指示時にdestinationが既存slot自身なら自己コピーしない。

Native802.11受信のQoS Controlは保持・除去どちらも許されるが、802.1D priorityはOOBで必須。
Windows10 WDI契約をRT8.1へ代用していない。Windows8.1 WDKの実型でcompileする。
原文とhost検証ログはプロジェクトrootの専用log配下に保存し、sourceへ混ぜない。

## 再現

hostは `make build/mt6630_native_hif_rx_test build/mt6630_native_nbl_test build/mt6630_native_receive_test` 後、3実行ファイルを実行する。
前者はASan/UBSanも実施。変換・長さ・TID・暗号descriptor・入力不変・優先度OOB復元・NBL/credit ownershipを確認する。
実機試験はmainが後段で行う。SSID/credentialsを要求・保存・公開しない。

`tools/ci/rebuild-mt6630-qos1014.ps1` は固定cacheのsource/header closureを検証してcore18objを再利用、
core11objとstandalone NDIS12objをcompileする。BT用NDIS objectは再利用もlinkもしない。
