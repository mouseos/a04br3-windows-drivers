# Mt6392Keys post reader: 静的設定とWDF時刻の観測

fresh132→fresh134のbounded native clone raw比較では、Mt6392Keys直下の6値と全子key構造は一致。Parameters/Wdf内TimeOfLastSqmLogだけがREG_QWORD/8byteのまま変わった。KmdfLibraryVersion/WdfMajorVersion/WdfMinorVersionも不変。完全subtreeの保存要求は不成立であり、旧failed receipt/errorsは正しい失敗記録として保持する。

変更はpost reader出力だけ。旧serviceごとのexpected/observed完全fingerprintとequal、全体full_service_preservation_equalを明示し、固定Mt6392Keys/Parameters/Wdf/TimeOfLastSqmLogのraw8byte/typeを追加観測する。型違いは拒否、別path/valueへ一般化しない。元の完全snapshot不一致errorsと非0終了は維持し、時刻を除外した成功へ読み替えない。prepare/native arm/SCM/driver/凍結mediaは変更しない。

rawのFILETIMEとしての値は2014-01-19T00:52:03.4506058Z→2026-11-08T18:57:50.0892793Z。UTC/localのRTC同期成功をこのvalueだけから主張しない。公開Microsoft WDF win-10.0.10041.0（commit058a020ccd9db55bb8406323e78a6849e00cc5d4）のfxtelemetrykm.cppはParameters/Wdfへシステム時刻をREG_QWORDで記録する同系機構を示すが、名前はTimeOfLastTelemetryLogであり実RT8.1 WDFの同一writer証明にはしない。keypad1.2固定sourceのdriver/INFは本valueの直接書込みを含まない。実WDF writerのinstruction追跡は未実施。

次armは最新fresh134とそこで観測した正確なfingerprintを基点にする。runtime動的値であることを理由に既存完全保存guardを一律緩和しない。静的設定の不変は別のraw比較結果として記録する。
